## 分類の目安

- **読み方の失敗**（F-1、F-5、F-6、F-9）：図面をどう読むか。v3 では、AI が建物の理解で読み、確定は書類との照合と人（B-2、C-5）。
- **器と同一性の失敗**（F-2、F-7、F-8）：何に ID を付け、どう引き継ぐか。v3 では、要素と境界に ID、節点は計算、器は全体を受け入れる形（B-7、E-1、E-2）。
- **確定の失敗**（F-3、F-4）：承認なしに値が動く経路。v3 では、採用は人だけが書き、仕組みで止める（B-9、D-3）。
- **守りの失敗**（F-11、F-12、F-13）：守りを入れたつもりで、実際の環境では効いていなかった。または、止めていない道（DB への直接の書き込み）が残っていた。v3 では、守りを入れたら手元の Windows の PC で実際に止まることを確かめ、守りが効かない環境では確定の操作を伴う作業をしない（D-3）。残っている穴（F-13）は、問題になったときに署名で閉じる。
- **文書の失敗**（F-10）：前提の書き直し。正本は一つ、番号で指す（G-1）。
