# 段階2（一部屋を間仕切で二つに分ける・右の部屋にだけ室名あり）の期待値

架空のデータです。ハッカソン期間中（2026年11月）に作成しました。図面（DXF）は設計者がJw_cadで描き、この期待値の表は、claude.ai のチャットの Claude の補助を受けて作成しました。

## 図面の約束

- 単位はmm。原点は通り芯X1とY1の交点。
- 段階1の図面（6000 × 4000、外壁4辺）に、間仕切を1本足したもの。
- 間仕切は x = 2300 の位置（X1から2.3m、X2から3.7m）。南の壁（y = 0）から北の壁（y = 4000）まで通っている。間仕切の壁芯線（WALL_CENTER）も描いてある。
- レイヤは段階1と同じ（GRID、ROOM_BOUNDARY、ROOM_NAME、WALL_CENTER）。
- 室名の文字は「101 事務室」が1つだけ。位置は (3000, 2000) で、右の部屋の中にある（段階1の図面にあった文字が、元の部屋の中央に残った形）。左の部屋には室名の文字がない。
- 壁の型は、取り込みコマンドで既定の WT-3 を全部の壁に指定する。壁の型の違いは、このデータではテストしない（段階3で決める）。
- 仕上表は、段階1のもの（101 事務室、天井高 2700）をそのまま使う。

## 実行方法（予定）

```
python -m building_db import samples/step2/step2.dxf --db out/step2.sqlite ^
    --wall-types samples/step1/wall_types.csv ^
    --finish-schedule samples/step1/finish_schedule.csv ^
    --default-wall-type WT-3
python -m building_db report --db out/step2.sqlite
```

## 期待値（テストの対象）

IDの番号は、実装の順序で変わるので、テストしない。部屋は、x の範囲で見分ける（左：x 0〜2300、右：x 2300〜6000）。

| 項目 | 期待値 |
|---|---|
| 通り芯 | 4本（X1=0、X2=6000、Y1=0、Y2=4000）。段階1と同じ |
| 節点 | 6か所。角の4か所（(0,0)、(6000,0)、(6000,4000)、(0,4000)）と、T字の接点2か所（(2300,0)、(2300,4000)） |
| T字の接点 | 2か所。境界線が3本集まる節点が (2300,0) と (2300,4000) |
| 部屋割り線（境界線） | 7本。南：2.300 m と 3.700 m、北：3.700 m と 2.300 m、東：4.000 m、西：4.000 m、間仕切：4.000 m。合計 24.000 m |
| 共有する境界線 | 1本（間仕切）。左右の二つの部屋の輪郭に、向きを逆にして含まれる |
| 閉じた輪郭 | 2つ（左：x 0〜2300、右：x 2300〜6000） |
| 部屋 | 2室 |
| 左の部屋 | 室名なし。面積 9.20 ㎡、周長 12.600 m、天井高は**未設定**（仕上表と結びつかないので、2700などを推測で入れない） |
| 右の部屋 | 室番号101、室名「事務室」（文字 (3000, 2000) が輪郭の内側にあるため）。面積 14.80 ㎡、周長 15.400 m、天井高 2700 mm（仕上表から） |
| 面積の合計 | 24.00 ㎡（段階1の部屋の面積と同じ） |
| 周長の合計 | 28.000 m（共有する間仕切 4.000 m を、両方の部屋で数えるため） |
| 壁 | 5本。外壁4本（6.000、4.000、6.000、4.000）と間仕切1本（4.000）。合計 24.000 m |
| 壁と境界線の対応 | 南の外壁と北の外壁は、それぞれ1本のまま、二つの境界線にまたがる。東・西・間仕切は、それぞれ境界線1本 |
| 壁の型 | 5本とも WT-3（既定を指定したため） |
| 要確認 | 1件。「室名がない」（左の部屋）。黙って名前を付けない。右の部屋は要確認なし |
| 取り込み直し | 同じファイルを2回取り込んでも、すべてのIDが変わらない（T23） |

## この段階で確かめたいこと

- 境界線がT字の接点で分かれ、壁が分割されないこと（1本の壁が二つの境界線にまたがる）。
- 一つの境界線を、二つの部屋が共有できること。
- 室名の文字が、位置によって、正しい部屋にだけ結びつくこと。
- 室名がない部屋を、推測せず、要確認に出すこと。天井高を勝手に引き継がないこと。
