# 段階2の変更（版の比較）の期待値【下書き】

架空のデータです。ハッカソン期間中（2026年11月）に作成しました。図面（DXF）は設計者がJw_cadで描き、この期待値の表は、claude.ai のチャットの Claude の補助を受けて作成しました。

## 比較する図面

基準の版は `step2.dxf`（間仕切が x = 2300）。新しい版として、次の2つを、それぞれ基準の版と比べる。

| ファイル | 変更の内容 |
|---|---|
| `step2_moved.dxf` | 間仕切を x = 2800 へ動かした。部屋割り線も壁芯線も、一緒に動かしてある（きれいな変更） |
| `step2_boundary_only.dxf` | 部屋割り線だけ x = 2800 へ動かした。間仕切の壁芯線は x = 2300 のまま（壁と境界線の食い違い） |

どちらも、外壁4本、通り芯、室名の文字「101 事務室」（位置 (3000, 2000)）は動かしていない。文字は、新しい間仕切（x = 2800）より200mm右にあり、右の部屋の中に残る。

## 同じ要素かどうかの判定（案・未決定）

位置が動くので、位置だけでは見分けられない。次の規則を、最初の案とする。

- 通り芯は、符号（X1、Y2など）で見分ける。
- 壁は、向きが同じで、接する壁の組が同じで、位置の移動が 1000 mm 以内なら、同じ壁とする（1000 mm は仮の値）。
- 境界線と節点は、接する壁・境界線のつながりで引き継ぐ。部屋は、囲む境界線の組で引き継ぐ。
- 判定が一つに決まらないときは、IDを引き継がず、候補を示して要確認にする。黙って決めない。

## step2_boundary_only.dxf の期待値（基準の版との差分）

### 境界線と部屋は、step2_moved.dxf と同じ

境界線の移動は採用し、部屋の面積・周長を再計算する（左 11.20 ㎡ ／ 右 12.80 ㎡、周長 13.600 m ／ 14.400 m）。

### 壁は動かさない

| 項目 | 期待値 |
|---|---|
| 間仕切の壁（観測した位置） | x = 2300（図面の壁芯線は動いていない） |
| 間仕切の壁（採用位置） | x = 2300 のまま。承認がないので、勝手に動かさない |
| 間仕切の壁（期待位置） | x = 2800（境界線に従う設定のため） |
| ずれ | 500 mm |
| 壁のID | 基準の版と同じ（つながりで同じ壁と判定する） |
| 壁の長さ | 間仕切 4.000 m のまま。合計 24.000 m |

### 要確認は2件

1. 「室名がない」（左の部屋）。
2. **壁と境界線のずれ**：間仕切の壁が、境界線の期待位置（x = 2800）から 500 mm ずれている。壁のIDと境界線のIDを示し、次の2つの選択肢を出す。
   - 「境界線に合わせる」
   - 「追従を外す」

「壁のない境界線」と「境界線に重ならない壁芯線」の2件に、**バラバラには出さない**（同じ壁として判定できるため、1件のずれにまとめる）。

## 判断の記録（最小の形）

要確認2の選択を、記録として残す。記録する項目：対象のID（間仕切の壁）、選んだ内容、理由、根拠の種類（人）、日付、前提が有効かどうか。

| 選択 | 期待値 |
|---|---|
| 境界線に合わせる | 壁の採用位置が x = 2800 になる。図面の壁芯線は x = 2300 のままなので、「図面の修正案：壁芯線を x = 2800 へ」を出す（図面は自動で書き換えない）。図面が直るまで、「承認済み・図面未反映」と表示する |
| 追従を外す | follow_edge を外し、壁は x = 2300 のまま。ずれは「承認済みの例外」として記録され、要確認からは外れるが、レポートには残る |

どちらも、理由を一言添えられる（省略もできる）。記録は、次に同じ図面を取り込んでも、同じ壁に付いたまま残る。

## この段階で確かめたいこと

- 位置が動いても、同じ要素が同じIDで引き継がれること。
- 面積と周長の変化が、期待どおりに再計算されること（保存した値の書き換えではなく、計算し直し）。
- 壁と境界線のずれを、1件にまとめて示し、黙って直さないこと。
- 人の判断（選択と理由）が、壁のIDに付いて残ること。

## まだ決まっていないこと

- 同じ要素と判定する規則（上の案）と、1000 mm の値。
- 差分の表示の形（段階2では一覧でよい。図面ごとの影響一覧は、サンプル事務所で）。
- 「図面の修正案」の出力の形。
